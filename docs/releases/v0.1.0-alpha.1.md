# Leaf v0.1.0-alpha.1

Published 31 October 2026: https://github.com/frandavid100/leaf/releases/tag/v0.1.0-alpha.1

Leaf is an experimental GTK4/libadwaita document editor powered by WordCraft. This first **x86_64 alpha** is for testing copies of DOCX and ODT documents.

Download **Leaf-0.1.0-alpha.1-x86_64.flatpak**, open it with GNOME Software, and install. The GNOME 49 runtime is downloaded from Flathub if needed. See **INSTALL.md** for terminal installation, checksums and updates.

Includes text/paragraph formatting and styles, tables and inline images, tabs/windows, sidebar search/replace, configurable recovery, document properties and PDF export. The launcher uses the Leaf name/icon and accepts DOCX/ODT files.

**Limitations:** primarily Spanish interface, experimental document fidelity, no printing, floating-image controls or table resize handles. Use copies and check saved files in another editor. No automatic Leaf update feed; install later GitHub bundles over this one. This is not a Flathub publication.

Automated release-build tests and installed-Flatpak smoke checks run in GitHub Actions before publication. Clean GNOME OS and broad real-document manual testing are still needed. Source revision and runtime are included as assets. This project has used substantial AI assistance, including packaging; see the repository disclosure.
