# Leaf v0.1.0-alpha.1 — draft release notes

**Not published.** Complete the release checklist and replace this status with the actual release date only after the package has passed installation testing.

Leaf is an experimental GTK4/libadwaita document editor for Linux, powered by the unmodified WordCraft engine. This first alpha is intended for testing copies of documents.

## Included features

DOCX/ODT editing and saving, PDF export, text/paragraph formatting and styles, tables and inline images, tabs/windows, sidebar search/replace, heading navigation, undo/redo and configurable recovery/autosave.

## Known limitations

Complex document fidelity and format preservation need broader testing. Floating-image positioning, table resize handles, formulas and printing are not exposed. The interface is currently primarily Spanish. The alpha is not recommended for editing the only copy of important work.
