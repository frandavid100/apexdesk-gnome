# AI assistance

Leaf's native frontend has been developed with substantial AI assistance under the project owner's direction. This includes a large portion of the GTK/libadwaita host and editing adapters, integration/regression tests, CI configuration, GitHub Flatpak packaging scripts and project documentation. The original Leaf SVG icon and symbolic companion were also created with AI assistance.

This is an approximate scope statement, not an audited line-count percentage. WordCraft is pinned to a Git revision. The sole compatibility exception is a narrow ODT preservation patch in the vendored wordcraft-formats crate; other engine crates and the renderer remain unchanged. This statement does not claim knowledge of how upstream code was authored. Existing dependency licenses and attribution continue to apply.

Automated CI and screenshot inspection have been used to validate changes. They do not prove correctness, complete document fidelity, accessibility or comprehensive human code review. The owner has tested and directed individual iterations; broader real-document testing and maintenance review are still needed.

This disclosure is not a Flathub submission or an assertion of eligibility. Current Flathub requirements include restrictions on AI-assisted manifests and automated submission interactions. A human maintainer must review the current policy independently before preparing any submission.
